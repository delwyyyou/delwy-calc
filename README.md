# delwy-calc

**delwy Calculator**

**delwy Calculator** is an Android calculator application built with **Kotlin** and **Jetpack Compose**.

## Features

- Standard calculator functionality
- Engineering mode
- Unit converters
- Material You-inspired interface
- Android-native user experience

## Technology Stack

- Kotlin
- Jetpack Compose
- Material Design 3
- Gradle

## Building

Clone the repository:

```bash
git clone https://github.com/delwyyyou/delwy-calc
cd delwy-calc
```

Build the debug APK:

```bash
./gradlew assembleDebug
```

The generated APK can be found in:

```text
app/build/outputs/apk/debug/
```
